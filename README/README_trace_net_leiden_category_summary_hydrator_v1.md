# TRACE-Net Leiden Category Summary Hydrator v1

Read-only TRACE-Net expansion module that hydrates Leiden communities with category summaries using category-aware overlay, element taxonomy, Dublin Core refined records, and graph UI overlay data.

Communities and category labels remain advisory navigation/ranking hints only. This module never grants answer permission or claim-proof authority.

## Outputs

- `trace_net_leiden_category_summary_hydrator_v1.json`
- `trace_net_leiden_category_summary_hydrator_v1_quality.json`
- `trace_net_leiden_category_summary_hydrator_v1_records.jsonl`
- `trace_net_leiden_category_summary_hydrator_v1.md`

## Safety

- No Postgres writes
- No Qdrant writes
- No OpenSearch writes
- No source-truth mutation
- No answer permission
- No claim-proof authority
