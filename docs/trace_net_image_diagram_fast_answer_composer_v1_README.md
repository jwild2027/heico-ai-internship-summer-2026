# TRACE-Net Image Diagram Fast Answer Composer v1

Deterministic fast composer for `image_or_diagram` questions over the image visual evidence pack. It only cites linked trusted OCR/table/figure-item proof. It refuses to identify parts from LLaVA-only or OCR-only LOW observations.

The composer explicitly blocks unsupported claims about interchangeability, effectivity, fit, replacement approval, and installation safety.
