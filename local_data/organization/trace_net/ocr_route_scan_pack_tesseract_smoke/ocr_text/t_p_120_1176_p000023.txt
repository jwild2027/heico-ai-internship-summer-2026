(5) VENDOR CODE Column.
This column lists the item vendor's codes.
For EMBRAER part numbers, the vendor code is VS4956.
Refer to the Vendor's List to identify the vendor's name and address.
(6) EFF FROM TO Column.
The EFFECTIVITY column enables the identification, through the letters (A), (B), (C), etc., of
assemblies and parts applicable to different probable versions.
NOTE: When blank, the EFFECTIVITY column indicates that the assembly is applicable to
any possible configuration.
(a) UNITS PER ASSY Column.
The quantity of units per assembly, in this column, indicates the total of identical items,
included with the same index number (item), which is required per assembly.
When an item is listed as a reference, the abbreviation REF is inserted in this column.
NOTE: Referenced items must not be used as information source for procurement.
The abbreviation AR (as required) also appears in this column.
