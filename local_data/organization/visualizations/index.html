How to read this graph

Document
The scanned manual/package root. In this run it should be one document.
ATA section

Page
The main hub. Every answer should resolve back to a page.
Evidence
Source link, TIFF file, OCR file, page context, part mentions.
Traits
Game-character style status effects: role, visual class, source-ready, blank, answer-ready.
