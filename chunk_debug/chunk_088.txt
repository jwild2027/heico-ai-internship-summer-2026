Network architecture documentation tools that use automated topology 
discovery technologies can only capture details from IP-based networked 
devices. Many OT environments contain isolated systems, components, 
or systems connected on non-IP networks. The OT environment may not 
be technically capable of using automated network architecture 
documentation tools, and manual processes may be required to document 
these components.
