# Document organization export inspection

This patch adds a read-only CLI that inspects the JSON artifacts generated by
`export_document_organization.py` as if a future UI/API were consuming them.

It checks that the expected export files exist and that the exported page,
ATA, and part trees can be read without opening the SQLite database.

## Run

```bash
python scripts/inspect_document_organization_export.py --strict --part 120-37313-001 --ata 25-21-00 --write-json
```

Default export directory:

```text
local_data/organization/export
```

Output JSON:

```text
local_data/organization/export_inspection.json
```
